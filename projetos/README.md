# Projetos

Este índice será preenchido conforme os projetos forem documentados.

## Como cadastrar

1. Use o [modelo de projeto](../modelos/projeto.md).
2. Crie uma pasta por projeto ou um repositório independente para o código.
3. Adicione abaixo nome, descrição, status e link.

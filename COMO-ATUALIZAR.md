# Como atualizar este portfólio

## Comece pelo currículo

1. Abra `curriculo/curriculo-matriz.md`.
2. Clique no lápis para editar.
3. Substitua os campos entre colchetes por informações conferidas.
4. Use **Preview** para revisar e **Commit changes** para salvar.

O currículo-matriz reúne toda a trajetória. Preserve suas experiências nele e crie versões menores na pasta `curriculo/versoes` para oportunidades específicas.

## Adicione um projeto

1. Copie o conteúdo de `modelos/projeto.md`.
2. Abra `projetos`, escolha **Add file > Create new file**.
3. Digite `nome-do-projeto/README.md` como nome do arquivo.
4. Preencha problema, objetivo, sua participação, solução e evidências.
5. Salve e inclua o link no índice de projetos.

Para projetos com código próprio, dependências e execução independente, use um repositório separado e adicione o link no índice.

## Organize os arquivos

- Use nomes curtos em minúsculas e hífens, sem espaços: `analise-de-vendas`.
- Mantenha a documentação junto do projeto.
- Use dados fictícios ou públicos em exemplos.
- Este repositório é público: revise documentos antes de publicá-los.
- Não envie senhas, chaves de acesso, dados de clientes ou documentos internos.
- PDFs de currículo podem ficar em `curriculo/versoes`.
- Certificados podem ser adicionados pela opção **Add file > Upload files**.

## Ordem sugerida

1. Preencher o currículo-matriz.
2. Documentar um primeiro projeto.
3. Registrar formação e certificados.
4. Atualizar os links e a apresentação da página inicial.
